# CopyJamie

Email copywriter portfolio styled as a fake Gmail inbox — visitors click emails to read real copywriting samples.

Static site: vanilla HTML/CSS/JS, no build step, no framework. Hosted on GitHub Pages at copyjamie.com (CNAME).

- `index.html` — inbox + email detail views
- `style.css` — Gmail-inspired styling
- `app.js` — inbox interactions and email navigation
- `contact.html`, `privacy.html` — secondary pages
